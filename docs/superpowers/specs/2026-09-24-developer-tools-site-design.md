# 开发者工具网站：首版设计规格

日期：2026-09-24

## 目标与边界

为个人和团队日常开发提供一个打开即用的工具网站，减少在多个网站之间切换。首版只提供 JSON 解析、Diff 对比和时间戳转换三个工具。使用效率和输入隐私优先于公开产品增长。

应用是纯静态网站：开发阶段在本机启动并通过浏览器访问；后续可把构建产物部署到个人云服务器并通过公共域名访问。三个工具的输入与计算均留在浏览器中，不调用业务后端，也不把输入放入 URL。首版不提供账号、团队共享历史、分析统计、PWA 安装、URL 编解码或 Base64 编解码。

## 技术与模块结构

使用 React、TypeScript 和 Vite。共享应用外壳负责导航、工具入口、通用输入体验、复制反馈和错误提示；三个工具各有独立页面与独立的纯计算模块。Diff 工具内部将文本比较和 JSON 结构比较分开实现。页面不依赖后端路由或服务端渲染，生产构建可由静态文件服务器提供。

工具输入按页面分别写入当前标签页的 `sessionStorage`，刷新后恢复；普通关闭标签页后会话结束。浏览器的“恢复关闭的标签页”功能可能恢复会话内容，因此该机制不承诺安全销毁敏感数据。提供显式清空输入的操作。会话存储不可用或配额不足时，工具仍可运行，并显示“本次输入无法在刷新后恢复”的提示。

## 页面与交互

首页列出三个工具并提供快速切换入口。所有页面以桌面浏览器为主要使用场景，同时保证窄屏可操作。输入区允许粘贴、编辑、清空和复制；错误不会清除用户输入。处理结果中的用户文本按纯文本呈现，不作为 HTML 执行。

### JSON 解析

- 粘贴 JSON 后可校验、格式化和压缩。格式化输出使用统一缩进；压缩只移除非必要空白，不改变数据值。
- 解析失败时展示可定位的错误位置及原因；成功时给出明确状态。
- 提供“转义”和“去转义”：转义把原始文本变成合法的 JSON 字符串字面量；去转义接收合法的 JSON 字符串字面量并还原原始文本。去转义输入不是字符串字面量时显示错误，不猜测输入格式。
- 各操作显示独立结果，避免覆盖尚未复制的原始输入。

### Diff 对比

提供“文本”和“JSON”两种模式。两侧原始输入分别保留在当前标签页；切换模式不覆盖另一模式的输入。

文本模式按行比较普通文本或代码，展示新增、删除和修改；保留空白与换行的差异。左右并排显示，长行可横向滚动。

JSON 模式先分别解析两侧输入，再按结构建立统一的行序，最后左右并排展示。相同字段路径占同一行，缺失字段的一侧保留空位；层级缩进保留。字段顺序不同但键、值及结构相同的对象视为相同，不标记差异。每个对象层级采用左侧字段顺序，右侧独有字段追加在该层级末尾。用户可以只看差异，也可以查看完整结构。字段新增、删除、值变化和类型变化分别有清晰标记。

数组默认按位置比较。对于元素为对象的数组，用户可针对具体数组路径指定标识字段，例如 `items` 使用 `id`；该数组按标识值匹配元素，并以左侧顺序展示已匹配元素，右侧独有元素追加在末尾。标识值必须是字符串或数字，匹配时区分类型；相同标识的元素仅重新排序不视为内容变化。标识字段缺失、值不是字符串或数字、或任一侧出现重复标识时，标识模式给出明确错误并停止该数组的对比，用户可修正输入或改回按位置模式；不静默配对。未配置标识字段的其他数组继续按位置比较。

任一侧 JSON 无效时显示对应侧的解析错误，不显示可能过期的比较结果。窄屏时保持两列字段对齐，并允许横向滚动整个对比区域，不将左右列拆成上下排列。

### 时间戳转换

- 用户明确选择秒或毫秒单位；输入整数时间戳可转换为日期时间，同时显示浏览器本地时区与 UTC。
- 用户输入日期时间后可反向得到秒和毫秒时间戳。日期时间输入按页面明确标示的本地时区解释；UTC 输出有独立标识。
- “使用当前时间”快捷操作立即填入当前时刻并显示秒、毫秒时间戳。
- 不凭数字长度自动猜测单位。无效日期、非整数时间戳和超出浏览器可表示范围的值给出明确错误。

## 错误处理与隐私

所有错误就地展示，不覆盖原输入。JSON 解析与去转义错误展示可定位信息；时间与数组匹配错误展示具体原因。计算不发送网络请求。部署到公共域名后仍保持浏览器本地计算与会话级输入保留。页面不引入会上传输入内容的遥测或第三方处理服务。

## 验收标准

1. 本机启动后可在浏览器访问首页和三个工具；生产构建可由静态文件服务器直接提供。
2. JSON 校验、格式化、压缩、转义、去转义对合法输入给出正确结果，对非法输入给出错误且保留输入。
3. 文本 Diff 能标出按行的增删改，并保留空白差异。
4. JSON Diff 对字段顺序不同但结构和值相同的对象不报差异；对字段增删、嵌套值变化与类型变化按统一字段行对齐展示。
5. JSON 数组按位置与按指定标识字段两种模式均可工作；缺失或重复标识会报错，不产生误导性的配对结果。
6. 时间戳的秒、毫秒、日期时间双向转换以及“使用当前时间”可用；本地时区和 UTC 标示清楚。
7. 刷新当前标签页能恢复三个工具各自的输入；普通关闭标签页后，新标签页不会取得旧输入；输入不出现在 URL 中。
8. 窄屏下 JSON Diff 仍保持左右字段在同一行，可横向浏览；用户输入不被当作 HTML 执行。

## 后续可能扩展

URL 编解码、Base64 编解码和 UUID 生成可在后续按使用频率加入。首版不为它们预设插件平台；共享外壳与独立计算模块已足够支持增量扩展。
