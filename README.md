# Dev Tools

一个纯静态、浏览器本地运行的开发者工具站。首版包含：

- JSON 校验、格式化、压缩、转义与去转义
- 文本 Diff 与结构化 JSON Diff
- 秒/毫秒时间戳和本地日期时间双向转换

所有工具输入与计算都留在浏览器中，不调用业务后端，也不会把输入写入 URL。输入使用当前标签页的 `sessionStorage` 保存，刷新后可恢复；关闭标签页后通常会结束会话，但浏览器的“恢复关闭的标签页”功能可能同时恢复会话数据。

## 环境要求

- Node.js `^20.19.0` 或 `>=22.12.0`
- npm（使用仓库内的 `package-lock.json` 安装确定版本）

## 本地运行

```bash
git clone https://github.com/C-Liueasymoney/dev-tools.git
cd dev-tools
npm ci
npm run dev
```

Vite 会输出本地访问地址，默认通常是 `http://localhost:5173`。

## 验证

```bash
npm test -- --run
npm run typecheck
npm run build
```

构建产物位于 `dist/`。可以用任意静态文件服务器托管；本机快速检查可运行：

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 `http://localhost:4173`。

## 使用说明

### JSON 解析

输入 JSON 后可校验、格式化或压缩。转义会把任意文本转为合法的 JSON 字符串字面量；去转义只接受合法的 JSON 字符串字面量。

### Diff 对比

文本模式按行显示增删改，并用可见符号标出差异行里的空格、Tab、CR 和 LF。JSON 模式按完整字段路径对齐，字段顺序不同不算差异。

对象数组默认按位置比较。需要忽略数组元素顺序时，启用“按标识字段匹配对象数组”，填写数组的 JSON Pointer 路径（例如 `/items`）和直接子字段（例如 `id`）。标识必须是字符串或数字，缺失或重复时会停止该数组的比较并显示错误。

### 时间戳转换

时间戳必须明确选择秒或毫秒，不会根据数字长度猜测。日期时间输入按页面显示的浏览器本地时区解释，同时输出本地时间和 UTC。

## 限制与隐私

- 本项目没有账号、业务后端、遥测或第三方输入处理服务。
- `sessionStorage` 不是敏感数据的安全销毁机制；需要立即移除输入时请使用页面上的清空操作。
- 日期时间结果依赖浏览器所在设备的时区设置。
- 生产环境只需要静态托管 `dist/`，不需要服务端路由或 SSR。
